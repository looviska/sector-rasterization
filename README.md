# Заполнение сектора окружности с интерполяцией цвета

Задание 2 (растеризация), вариант 7: реализовать метод для заполнения сектора
окружности. Добавить интерполяцию цвета при удалении от центра круга.

Единственная разрешённая операция вывода - заливка цветом одного пикселя
(`pixelWriter.setColor(x, y, color)`). Готовые методы рисования фигур не используются.

## Идея алгоритма

1. Сектор задаётся центром `(xc, yc)`, радиусом `r`, углом первого луча `startDeg`
   и раствором `sweepDeg` (против часовой стрелки).
2. Алгоритм идёт по строкам `y` (идея scanline). Для каждой строки считаются границы
   хорды круга `x in [xc - h, xc + h]`, `h = floor(sqrt(r^2 - dy^2))`, поэтому
   пиксели вне круга не проверяются.
3. Принадлежность угловому диапазону проверяется через знаки векторных произведений
   `M = OA x OP`, `N = OP x OB`: если оба неотрицательны, точка лежит между лучами.
   Для секторов больше 180 градусов проверяется дополнение (точка не лежит строго
   в секторе от OB к OA).
4. Цвет линейно интерполируется по расстоянию от центра:
   `c = c_center + (dist / r) * (c_edge - c_center)` по каналам a, r, g, b.

## Структура проекта

| Путь | Назначение |
|------|------------|
| `core/PixelSink` | единственная операция вывода `setPixel(x, y, argb)` |
| `core/ColorUtils` | упаковка ARGB и линейная интерполяция цвета |
| `core/SectorRasterizer` | сам алгоритм (`fillSector`) |
| `demo/SectorScene` | демонстрационная сцена из 12 секторов |
| `fx/*` | JavaFX-окно: `Application`, `Controller`, адаптер `FxPixelSink` |
| `src/test/.../SectorChecks` | проверки (29 штук), включая сравнение с эталоном на `atan2` |
| `src/test/.../ScenePngRenderer` | отрисовка сцены в PNG без JavaFX |
| `docs/report.pdf` | подробный отчёт: теория и разбор программы |

## Запуск

Проверки алгоритма (нужен только JDK 17+, без JavaFX и без интернета):

```
./scripts/check.sh
```

Отрисовка сцены и увеличенных фрагментов в PNG:

```
./scripts/render.sh docs/images
```

Окно JavaFX (нужен Maven и доступ к интернету для загрузки JavaFX):

```
mvn javafx:run
```

## Результаты тестирования

- Полный круг совпадает с определением `dx^2 + dy^2 <= r^2` пиксель в пиксель.
- Сектор и его дополнение вместе покрывают весь круг для раствора
  30, 90, 120, 179, 180, 181, 270, 350 градусов.
- Сравнение с независимой реализацией через `atan2` на 400 случайных секторах
  (около 737 тысяч пикселей): расхождений нет.
- Вырожденные случаи: раствор 0, отрицательный, больше 360, радиус 0 и отрицательный.
